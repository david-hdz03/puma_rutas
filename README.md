# puma_rutas
A new Flutter project.

## Build

To build the application, run the following command:

```bash
flutter build apk
```

This will create an APK file in `build/app/outputs/flutter-apk/app-release.apk`.

## Repository

To add this project to a repository, follow these steps:

1.  Initialize a new Git repository:

    ```bash
    git init
    ```

2.  Add all the files to the repository:

    ```bash
    git add .
    ```

3.  Commit the files:

    ```bash
    git commit -m "Initial commit"
    ```

4.  Add a remote repository:

    ```bash
    git remote add origin <repository-url>
    ```

5.  Push the files to the remote repository:

    ```bash
    git push -u origin main
    ```
